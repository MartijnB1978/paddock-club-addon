# Paddock Club Reeuwijk – Home Assistant add-on repository

Contains one add-on: `f1_paddock_club` (the F1 prediction game). See `f1_paddock_club/DOCS.md`.

Install as a local add-on: copy the `f1_paddock_club` folder into the `addons` share of Home Assistant
(Samba share add-on → `\\homeassistant\addons\`), then Settings → Add-ons → Add-on store → ⋮ → Check for updates.
It appears under "Local add-ons".
